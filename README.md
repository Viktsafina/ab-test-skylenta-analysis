# A/B-тест маркетинговой механики для ритейлера SkyLenta

## Описание проекта

Проект выполнен в рамках дипломной работы по аналитике данных.

Задача: проанализировать результаты A/B-теста для крупного ритейлера SkyLenta и оценить, стоит ли заменять баннеры в приложении на push-уведомления.

Контрольная группа получала баннеры с информацией об акциях и скидках.  
Тестовая группа получала push-уведомления.

Эксперимент длился 3 месяца.

## Цель исследования

Оценить влияние новой маркетинговой механики на:

- конверсию в покупку;
- средний чек;
- выручку;
- результаты по городам и торговым точкам.

## Данные

В проекте использовались три таблицы:

### Данные о покупках

- `id_order` — уникальный идентификатор покупки;
- `id_client` — уникальный идентификатор клиента;
- `amt_payment` — сумма платежа;
- `dtime_pay` — дата и время оплаты.

### Данные о клиентах

- `id_client` — уникальный идентификатор клиента;
- `dtime_ad` — дата и время показа рекламного воздействия;
- `nflag_test` — группа эксперимента: 0 — контроль, 1 — тест;
- `id_trading_point` — идентификатор торговой точки.

### Справочник регионов

- `id_trading_point` — идентификатор торговой точки;
- `city` — город.

## Этапы работы

1. Импорт и первичный анализ данных.
2. Проверка пропущенных значений.
3. Очистка некорректно заполненных торговых точек.
4. Объединение таблиц.
5. Расчёт флага покупки.
6. Анализ общих результатов A/B-теста.
7. Анализ результатов по городам.
8. Сегментация результатов по торговым точкам.
9. Расчёт статистической значимости.
10. Подготовка Excel-калькулятора для оценки эффекта.

## Использованные методы

- группировка и агрегация данных;
- визуализация распределений;
- t-test для сравнения средних значений;
- Mann–Whitney test для сравнения распределений;
- расчёт p-value;
- сегментация результатов по городам и торговым точкам;
- оценка прироста / падения выручки.

## Бизнес-смысл проекта

Проект показывает, как аналитик может использовать данные A/B-теста для принятия продуктового решения: стоит ли внедрять новую маркетинговую механику на всех пользователей или эффект недостаточно убедителен.
